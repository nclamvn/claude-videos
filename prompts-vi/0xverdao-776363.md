## Prompt (tiếng Việt)

```text
Hãy tạo một animation phong cách Minecraft bên trong một môi trường street view thật. Xếp chồng 15 khối TNT trên mặt đường, dựng một tòa tháp vàng và kim cương, thả một khối TNT khổng lồ từ trên trời xuống, và tạo những hố bom bị nổ tung vào chính bề mặt con đường thật. Triển khai thành một file HTML duy nhất, không dùng thư viện bên ngoài.
```

## Prompt gốc

```text
Create a Minecraft-style animation inside a real street view environment. Stack 15 TNT blocks on the road, build a gold and diamond tower, drop a giant TNT block from the sky, and create craters blown into the actual road surface. Implement this as a single HTML file without external libraries.
```
