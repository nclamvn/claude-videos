## Prompt (tiếng Việt)

```text
Hãy biến file này thành một video hoạt hình 2D, dùng giọng đọc kiểu BBC, với lời dẫn tiếng Anh và phụ đề tiếng Anh.

về hiệu ứng video / độ hoàn chỉnh của kịch bản / độ khớp giọng đọc / phối hợp nhạc và hiệu ứng âm thanh, hãy tự chọn
```

## Prompt gốc

```text
Turn the file into a 2D animated video, using a BBC-style voice, with English narration and English subtitles.

regarding video effects / script completeness / voice matching / music and sound-effects coordination, Choose those by yourself
```
