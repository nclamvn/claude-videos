## Prompt (tiếng Việt)

```text
Hãy tạo một phim ngắn generative dài 50 giây có tựa đề 'Painting the Night'. Không dùng asset hình ảnh nào. Tạo vân giấy, nét gạch chì graphite, hiệu ứng lộ dần lớp sơn, các vì sao, chòm sao, vầng sáng mặt trăng và nhạc nền felt-piano ngay lúc chạy bằng JS thuần + WebGL.
```

## Prompt gốc

```text
Create a 50-second generative short titled 'Painting the Night'. Zero image assets. Generate paper grain, graphite hatching, paint reveal, stars, constellation, moon glow, and felt-piano soundtrack live at runtime with plain JS + WebGL.
```
