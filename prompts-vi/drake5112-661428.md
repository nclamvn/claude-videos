## Prompt (tiếng Việt)

```text
Hãy tạo một bài thuyết trình HTML tương tác giải thích khái niệm 'Network Effects', trong đó số kết nối tăng theo cấp số nhân khi số người dùng tăng (ví dụ 5x người dùng = 27x kết nối). Giao diện cần có một thanh trượt cho phép người xem tự điều chỉnh số người dùng và thấy sự thay đổi tương ứng về mật độ kết nối theo thời gian thực. Chỉ dùng HTML và JavaScript, không dùng asset hình ảnh bên ngoài. Kèm lời thuyết minh bằng giọng nói đồng bộ với các thay đổi hình ảnh.
```

## Prompt gốc

```text
Create an interactive HTML presentation explaining the concept of 'Network Effects' where connections grow exponentially as user count increases (e.g., 5x users = 27x connections). The interface should include a slider allowing the viewer to manually adjust the number of users and see the resulting change in connection density in real-time. Use only HTML and JavaScript without external image assets. Include voice narration synchronized with the visual changes.
```
