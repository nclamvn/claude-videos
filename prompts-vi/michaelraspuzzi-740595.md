## Prompt (tiếng Việt)

```text
hãy giải thích loop transformer trong một video ngắn hoạt hình kiểu youtube. tìm trên web vài bài báo khoa học thật để đọc nữa.

đổi cảnh liên tục, và làm cho mạch kể chuyện bằng hình ảnh hấp dẫn hơn. ngoài ra, đảm bảo phần hook tạo ra một khoảng trống tò mò về ứng dụng thực tế, vì sao điều này quan trọng.
```

## Prompt gốc

```text
explain loop transformers in a youtube animated short. search web for some real papers to read too.

switch up scenes, and make the visual narrative more compelling. also, make sure hook creates a curiosity gap for real world application on why this matters.
```
