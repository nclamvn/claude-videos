## Prompt (tiếng Việt)

```text
Cài Blender dưới dạng module Python vào môi trường Linux trên cloud, thực thi toàn bộ từ dựng cảnh tới render bằng script
Dựng sân khấu, ánh sáng, pháo giấy, chuyển động camera bằng code, vẽ bằng Cycles
Tự động hoá luôn cả hậu kỳ glow, flash, quang sai màu cho tới khâu xuất MP4
Nhạc nền cũng không dùng sample có sẵn. Tổng hợp kick, snare, bass, synth bằng code numpy
Phân tích độ cao hông trong điệu nhảy, xác định được tempo gốc khoảng 137BPM
Hiệu chỉnh thời gian điệu nhảy theo từng nhịp, để ở mọi nhịp cú nhún xuống khớp với kick trong khoảng ±0.5 khung hình
Cắt cảnh, ánh sáng, zoom, chuyển đổi chất liệu cũng đều khớp vào đầu nhịp, và ở cú đánh cuối cùng thì tất cả đứng yên
Camera được tính bằng Python ở mọi khung hình. Các cú như bổ nhào, lượn vòng quanh, cận mặt rồi lia ngang vụt ra
Ở đầu nhịp, chất liệu và mesh đổi sang chrome, vàng, hologram, voxel
```

## Prompt gốc

```text
クラウドのLinux環境にBlenderをPythonモジュールとして入れ、シーン構築からレンダーまで全部スクリプトで実行
ステージ、照明、紙吹雪、カメラワークをコードで組み、Cyclesで描画
グロー、フラッシュ、色収差の後処理とMP4化まで自動
BGMもサンプル素材なし。キック、スネア、ベース、シンセをnumpyのコードで合成
ダンスの腰の高さを解析し、本来のテンポが約137BPMと特定
拍ごとにダンスの時間を補正して、全拍で沈み込みがキックと±0.5フレームで一致
カット、照明、ズーム、質感の切り替えもすべて拍の頭に合わせ、最後の一撃で全員静止
カメラはPythonで毎フレーム計算。急降下、回り込み、顔のアップから横に振り抜くカットなど
拍の頭でクローム、ゴールド、ホログラム、ボクセルに質感とメッシュが変わる
```
