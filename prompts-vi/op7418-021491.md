## Prompt (tiếng Việt)

```text
Hãy làm giúp tôi một hiệu ứng động 「高光时刻」 (khoảnh khắc đỉnh cao) nguyên bản cho game mobile: [chủ thể, ví dụ: mở rương báu / thăng hạng / mở khóa thành tựu / Boss rơi đồ / nhân vật lên cấp].
Làm thành một trang web một file duy nhất có thể mở trực tiếp (HTML + CSS + JS), bấm một cái là phát trọn vẹn, hiệu ứng ngang tầm màn kết toán / màn trao thưởng của game mobile thương mại.

【Thế giới quan và phong cách】
- Mỹ thuật nguyên bản, không bắt chước bất kỳ game hiện có nào
```

## Prompt gốc

```text
帮我做一个原创的手游「高光时刻」动效：[主体，例如：开宝箱 / 段位晋升 / 成就解锁 / Boss 掉落 / 角色升级]。
做成一个可以直接打开的单文件网页（HTML + CSS + JS），点一下就能完整播放，效果对标商业手游的结算 / 奖励演出。

【世界观与风格】
- 原创美术，不要模仿任何现有游戏的
```
