## Prompt (tiếng Việt)

```text
Hãy dựng một timeline GSAP cho các thẻ UI với ràng buộc timing cụ thể: 280ms cho thẻ, 220ms cho tiêu đề, 160ms cho metadata, và stagger 60ms giữa các phần tử. Triển khai một vòng kiểm chứng trong đó animation được chạy từng khung hình bằng Playwright, so sánh screenshot để phát hiện overshoot hoặc lỗi, và vá code cho đến khi vượt qua các bước kiểm tra mà không phải viết lại toàn bộ.
```

## Prompt gốc

```text
Build a GSAP timeline for UI cards with specific timing constraints: 280ms for cards, 220ms for title, 160ms for metadata, and a 60ms stagger between elements. Implement a verification loop where the animation is stepped through frame-by-frame using Playwright, screenshots are compared to detect overshoot or errors, and the code is patched until it passes the checks without rewriting everything.
```
