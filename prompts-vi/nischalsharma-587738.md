## Prompt (tiếng Việt)

```text
Hãy làm một phim hoạt hình vuông dài 80 giây dưới dạng một file HTML duy nhất, dùng WebGL2 và JS thuần, không thư viện, không file hình ảnh, font hay âm thanh. Nó phải trông như một bức tranh khảm tường bằng kính và lá vàng mà các viên khảm chưa từng được gắn keo, nên chúng có thể nhấc lên, lật, bay đi và ghép lại thành những hình dạng mới.
```

## Prompt gốc

```text
Make an 80 second square animated film as a single HTML file, using WebGL2 and plain JS, with no libraries and no image, font or audio files. It should look like a glass and gold leaf wall mosaic whose tiles were never glued down, so they can lift, flip, fly and reform into new shapes.
```
