## Cách dùng một prompt

1. Mở một file prompt, sao chép khối dưới mục **Prompt (tiếng Việt)** hoặc **Prompt gốc**.
2. Dán vào Claude Opus 5.5 (Claude Code, ứng dụng Claude hoặc bất kỳ agent nào chạy Opus 5.5).
3. Yêu cầu nó render kết quả thành một file HTML duy nhất, rồi quay màn hình trang đó nếu bạn muốn có video.

Một số tác giả chỉ chia sẻ một phần prompt, hoặc chỉ mô tả kết quả trong bài đăng; các file đó có ghi chú rõ.

Bản dịch giữ nguyên code, URL, tên công nghệ và chữ hiển thị trên màn hình như bản gốc. Khi cần đúng tuyệt đối ý tác giả, hãy đối chiếu với **Prompt gốc** ngay bên dưới trong cùng file.
