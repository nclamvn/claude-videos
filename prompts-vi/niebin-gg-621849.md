## Prompt (tiếng Việt)

```text
<inputs> Hỏi tôi: 8 đến 12 trạng thái UI mà tôi muốn hình khối biến thành (ví dụ nút bấm, loader, trình phát, thanh trượt, công tắc, tab, biểu đồ, command palette, thông báo), thuần đen trắng hay một màu nhấn, và một bài hát miễn phí bản quyền khoảng 120 BPM (ví dụ Mixkit, miễn phí cho mục đích thương mại). </inputs>

<direction> Video UI motion đẳng cấp Dribbble. Để các hình khối hình học cơ bản biến hình mượt mà thành các thành phần UI được chỉ định, giữ thẩm mỹ tối giản, chuyển động trôi chảy và giàu độ đàn hồi, đồng bộ hoàn hảo với nhịp nhạc. Xuất ra file video phát được.
```

## Prompt gốc

```text
<inputs> 向我询问：8 到 12 个我希望形状变成的 UI 状态（例如按钮、加载器、播放器、滑块、开关、标签、图表、命令面板、通知），纯黑白或一种强调色，以及一首约 120 BPM 的免版税歌曲（例如 Mixkit，商业使用免费）。 </inputs>

<direction> Dribbble 级别的 UI 动效视频。让基础几何形状平滑变形为指定的 UI 组件，保持极简主义美学，动作流畅且富有弹性，与音乐节奏完美同步。输出为可播放的视频文件。
```
